# Page fixtures

These HTML files were **generated by the game's own PHP templates**, not written by hand.
`gen_nation.php` and `gen_rest.php` strip the `include()` lines out of `viewnation.php`,
`viewalliance.php`, `messages.php` and `news.php`, supply the variables the backend would
normally have filled from the database, and render the result.

That matters: a hand-written fixture only proves the parser agrees with whoever wrote the
fixture. These prove it agrees with the game.

To regenerate against a newer CLOP checkout:

```bash
cd /path/to/CLOP/clop
for f in viewnation news messages viewalliance; do
  sed 's/^include(.*);$//' $f.php > /tmp/_${f}_render.php
done
php gen_nation.php && php gen_rest.php
```
